# data/

## nid_names.txt

Symbol names used to show readable names instead of raw NIDs (e.g. `Up36PTk687E` → `sceVideoOutOpen`).
One name per line. PS5C computes each NID from the name (`SHA1(name + salt)`), so a wrong line can
never mislabel a NID; it simply never matches.

- Source: shadPS4 `src/core/aerolib/aerolib.inl`, GPL-2.0-or-later (compatible with PS5C's license).
- Generated by `tools/gen_nid_names.py`, which recomputes every NID and drops entries that don't match.
- The file header records the exact shadPS4 commit used.

To regenerate:

```bash
python tools/gen_nid_names.py <shadPS4>/src/core/aerolib/aerolib.inl data/nid_names.txt "<commit>"
```

The names come from the PS4 system libraries. Most PS5 libraries share them; PS5-only functions
will show up as raw NIDs until names are added.

## fonts/

`NotoSans-Regular.ttf`: the font libSceFont draws with when `user/fonts/` holds none
(a PS5's own system fonts, copied from the console, go there and take precedence).
Noto Sans 2.015 (Latin, Greek, Cyrillic), hinted TTF from
https://github.com/notofonts/notofonts.github.io at commit `e408cf09bf2042e9fe0d7d22789c29510e876359`
